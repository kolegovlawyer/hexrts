## [Дата: 2024-XX-XX] - Система ИИ ботов для PvE (Серверная архитектура)

### ✨ Новые функции

#### 🤖 Серверная система искусственного интеллекта
- **Добавлен класс `Bot`** (`scripts/bot.gd`) - полноценная ИИ система для управления ботами
- **Серверный UI управления** - простой интерфейс администратора на сервере для добавления/удаления ботов
- **Стратегическое планирование** - боты используют три стратегии: расширение, оборона, атака
- **Тактическое поведение** - автоматическое управление юнитами, спавн, захват гексов

#### 🧠 Поведение ботов
- **Автоспавн** - боты автоматически спавнят командные юниты на первые очки найма
- **Захват территорий** - ИИ отправляет командные юниты для захвата нейтральных гексов
- **Система взаимопомощи** - при атаке на юнита бота, соседние юниты приходят на помощь
- **Отступление командных юнитов** - при угрозе командные юниты отступают в безопасные зоны
- **Адаптивная стратегия** - боты меняют поведение в зависимости от ситуации

#### 🔗 Система сигналов
- **Новые сигналы в `BaseUnit`**:
  - `under_attack(attacker, victim)` - уведомление о начале атаки
  - `attack_started(attacker, target)` - сигнал начала атаки
  - `unit_died(dead_unit)` - уведомление о смерти юнита
- **Интеграция с группами** - боты используют groups и signals для реакции на события

### 📋 Алгоритмы ИИ

#### Стратегическое планирование
1. **Расширение** (`expand`) - захват нейтральных гексов
2. **Оборона** (`defend`) - группировка юнитов для защиты контролируемых гексов  
3. **Атака** (`attack`) - координированные атаки на вражеские позиции

#### Тактические решения
- **Оценка угрозы** - анализ соотношения вражеских и союзных юнитов
- **Контроль территории** - подсчет контролируемых гексов
- **Управление ресурсами** - автоматический спавн юнитов при достаточных очках

### 🎯 Особенности реализации

#### Архитектурные принципы
- **Неинвазивность** - система ботов не изменяет существующий игровой код
- **Модульность** - боты представлены отдельным классом с четким интерфейсом
- **Производительность** - принятие решений каждые 2 секунды, проверка спавна каждую секунду
- **Масштабируемость** - поддержка множественных ботов на сервере

#### Интеграция с игровыми системами
- **Система очков** - боты используют существующую валидацию спавна через `GameManager`
- **Система команд** - полная интеграция с `TeamSystem` и `PlayerProfile`
- **FOB система** - боты используют существующую очередь спавна через `base_fob.gd`
- **Сетевая архитектура** - боты работают как специальные клиенты

## 🎮 Быстрый старт для тестирования

### Простой тест PvE
1. **Запустить сервер**: Host → выбрать карту → Host
2. **Создать бота**: 
   - На сервере в панели управления выбрать команду
   - Нажать "➕ Добавить бота"
   - Бот появится в списке и начнет играть
3. **Подключить игрока**:
   - В отдельном клиенте: Join к серверу
   - Выбрать противоположную команду
4. **Наблюдать за поведением**:
   - Бот начнет спавнить командные юниты через ~10 секунд
   - Будет захватывать ближайшие нейтральные гексы
   - При атаке на его юнитов - вызовет подкрепления

### 🔍 Отладка проблем

#### Если боты не спавнят юнитов:
1. Проверьте консоль на сообщения: `💰 SERVER UI: У бота X очков найма`
2. Ищите сообщения: `🤖 SERVER UI: Принудительный спавн для бота`
3. FOB должен показать: `✅ SERVER UI: FOB назначен боту`

#### Если юниты ботов видны врагам:
1. Проверьте сообщения: `👁️ VISIBILITY: Настройка видимости для юнита`
2. Должны быть логи: `- Скрыт от player_id: X`
3. Враги не должны видеть: `- Показан союзнику player_id: X`

#### Если боты не реагируют:
1. Ищите сообщения: `🧠 BOT: Принятие стратегических решений`
2. Проверьте подключение сигналов: `📡 GAME: Подключение сигналов юнита`
3. Должны быть логи: `⏰ BOT: Проверка возможности спавна`
